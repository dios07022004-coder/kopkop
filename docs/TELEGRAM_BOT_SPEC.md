# ТЗ: Telegram-бот «Можно купить?» (kapkapmoney)

## 1. Цель
Финансовый советчик в моменте прямо в Telegram: пользователь пишет цену покупки —
бот мгновенно отвечает «можно / подожди / копить N мес» на основе его бюджета.
Бот — ежедневная точка входа и виральный канал; сайт — кабинет и полная версия.

## 2. Экосистема (единое ядро)
```
                ┌──────────────────────────┐
   Сайт (web) ──┤  src/lib/finance/* (ядро) ├── Telegram-бот
   Приложение ──┤  Supabase (БД + auth)     │   (/api/telegram/webhook)
                └──────────────────────────┘
```
- **Один источник правды формул** — `src/lib/finance`. Бот, сайт и будущее приложение считают одинаково.
- **Одна БД** — Supabase. Аккаунт пользователя общий: оплата на сайте = доступ в боте, и наоборот.
- Будущее приложение (PWA/нативное) использует те же API-роуты.

## 3. Данные
Таблица `public.telegram_users`:
| поле | тип | назначение |
|---|---|---|
| tg_id | bigint PK | id чата Telegram |
| income | int | доход/мес |
| mandatory | int | обязательные/мес |
| savings | int | откладывает/мес |
| step | text | шаг диалога настройки (FSM) |
| user_id | uuid | связь с аккаунтом сайта (для подписки/синхрона) |
| created_at/updated_at | ts | |

## 4. Сценарии (MVP — реализовано)
- **/start** — приветствие + краткая инструкция.
- **/setup** — пошаговая настройка: доход → обязательные → откладываю. Сохраняется в БД.
- **Проверка покупки** — сообщение `кроссовки 8000` или `8000` → вердикт:
  - 🟢 «Можно — останется X на жизнь»
  - 🔴 «Копить N мес по Y» (если цена больше свободного)
- **/plan** — текущая картина: свободно/мес, ≈ в день.
- **/help** — как пользоваться.
- Безопасность вебхука: проверка `X-Telegram-Bot-Api-Secret-Token`.

## 5. Фаза 2 (дорожная карта)
- **Привязка аккаунта**: команда `/link` → бот даёт ссылку `kapkapmoney.ru/link?code=...`;
  после входа аккаунт связывается с `tg_id` (заполняем `user_id`). Тогда оплата на сайте
  открывает «полную версию» и в боте.
- **Полная версия в боте**: распределение по категориям, цели, история, безлимит проверок.
  Бесплатно — базовый вердикт; платно (399 ₽, оплата на сайте) — расширенное.
- **Пуши (бесплатно через Telegram)**: «новый месяц — обнови план», «близко к лимиту»,
  «до цели N взносов». Cron на сервере → рассылка по `telegram_users`.
- **Дневной лимит + быстрый учёт** (по желанию): «сегодня осталось X».
- **Inline-режим**: `@bot 8000` прямо в любом чате.

## 6. Инфраструктура / запуск
- Токен бота от @BotFather → env `TELEGRAM_BOT_TOKEN`.
- Секрет вебхука (любая строка) → env `TELEGRAM_WEBHOOK_SECRET`.
- Установить вебхук (один раз):
  ```
  curl "https://api.telegram.org/bot<TOKEN>/setWebhook?url=https://kapkapmoney.ru/api/telegram/webhook&secret_token=<SECRET>"
  ```
- Бот работает на том же Next-сервере (роут `/api/telegram/webhook`), отдельный процесс не нужен.

## 7. Метрики
- DAU бота, число проверок покупок, доля «подождал/отказался», конверсия бот → оплата на сайте.
- UTM `utm_source=tg` на ссылках из бота на сайт → видно в админке.
